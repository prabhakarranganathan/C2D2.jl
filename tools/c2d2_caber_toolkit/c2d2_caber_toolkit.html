Polymer and solution

The fluid is a C2D2 fluid fixed by NK, φ and h*K. The steady-extension curve is computed once for each distinct (NK, φ, h*K).
Kuhn steps per chain, NK = Mw/MK. For polystyrene we use MK ≈ 742 g mol−1, so 2.8 M → 3774.
Scaled concentration c/c*, read as the volume fraction of pervaded coils (c* in the C2D2 convention of the report and paper). φ < 1 is dilute; φ > 1 is semidilute.
The hydrodynamic-interaction (segmental friction) parameter of one Kuhn segment. It sets how strongly the drag changes as the coil stretches and as the solution crowds. We use 0.015 for PS in DEP.
1 is the single-mode (dumbbell) C2D2 model. With more modes (10 to 100) the chain's fast internal modes are resolved; in our tests 10, 30 and 100 modes agree closely. Cost grows with Nm: a single-mode CaBER run takes seconds; 100 modes takes a few minutes.
Only matters when Nm > 1. blob lets each mode's relaxation time cross over from Zimm to Rouse with the blob picture; it follows the drag as the solution crowds and the chain stretches. This multimode spectrum is newer than the single-mode model and has not been through peer review yet. The pure Rouse and Zimm scalings are useful checks.

Flow and starting state

Deborah number of the thinning filament, De = λ1/tv, with tv = ηsR0/σ the solvent viscocapillary time. λ1 is the longest relaxation time of the solution (e.g. from SAOS), not a time estimated from the bead drag. The code integrates in units of tv, so t/λ1 = t/De.
From your experiment: λ1 [s] ηs [Pa s] σ [N/m] R0 [mm]
Hencky strain of an affine stretch of the coils at t = 0, standing in for the stretch left by the step-strain that forms the filament. 0 starts from equilibrium. ε0 = 1 is a reasonable upper estimate for a CaBER step.
With Nm > 1 the prestretch is applied to every mode, including the fast ones, which then start far from equilibrium and relax back almost at once. That is not a physical starting state. We use prestretch only with the single-mode model.

Switch away from C2D2 only for comparisons.
RP is the scheme of the technical report and reproduces the published results (the default). The bare-blob model (BAREI / BARECUI) uses the bare Kirkwood–Riseman draining of the tension and correlation blobs; the shielded-blob model (OESI / OESCUI) adds overlap-enhanced shielding of the hydrodynamic interactions. The CUI variants join the weakly and strongly screened limits with a Churchill–Usagi blend of exponent pφ; the I variants switch between them. Only the C2D2 drag model uses this setting.
Written only for OESCUI, BARECUI and CU. The default is 2 for the CUI schemes and 1.86 for CU (the fit to Martin's correlation at rest). Must be positive.
Written only for OESI and OESCUI. The overlap dressing is ψ = min(φ/Eq, 1): with 0 (default) the shielding is set by the overlap alone; 0.25 delays it as the chain stretches (stretch-delayed shielding).

Job scripts

Both scripts are written into the run folder. Use whichever suits the machine.
bash run_local.sh runs everything one after another in a single Julia session (the code is compiled only once). bash run_local.sh 4 runs four inputs at a time.
sbatch job.slurm submits an array job with one task per input.

This page sets up capillary-thinning (CaBER) simulations with the C2D2 model, writes a self-contained run folder with job scripts, and plots the results. With it you can sweep one of NK, φ, h*K, De or the prestretch ε0 while the other parameters stay fixed. For each distinct fluid (NK, φ, h*K), the matching steady uniaxial-extension curve is computed as well, so every transient trajectory can be read against its steady-state attractor.

6. Units and definitions


The code is written in dimensionless form. λ1 (= lambda0 = 1) is the longest relaxation time of the solution, and tv = ηsR0/σ is the solvent viscocapillary time.


    

  • De = λ1/tv. Time t in the outputs is in units of tv, so t/λ1 = t/De.
    • 

  • Wi = ε̇λ1, with ε̇ = −2 d ln R/dt the strain rate at the neck.
    • 

  • Hencky strain ε = 2 ln(R0/R).
    • 

  • M is the mean-square stretch of the chain relative to equilibrium. The column E2 = Σp Sp tr Mp equals Nm at equilibrium, so M = E2/Nm; the viewer plots M.
    • 

  • η̃p (column etaE1) is the polymer contribution to the extensional viscosity, scaled with n kBT λ1, where n is the number density of chains. Stresses tau_* are the polymer stress scaled with n kBT, in the solver's sign convention (negative in tension).
    • 

  • The mid-filament stress balance is 3Wi = (2X−1)De/R + K̃ N1,p. In terms of the output columns this reads viscstress = capstress + polystress, where viscstress = 3Wi is the solvent stress, capstress = (2X−1)De/R is the capillary stress and polystress = K̃N1,p is the polymer term. In the solver's sign convention polystress is negative in tension, so −polystress is the polymer's tensile stress. K̃ (column K_til) = U1φ weighs polymer stress against solvent stress, with U1 = UZλ1/λZ.
    •

7. Notes


    

  • With Nm > 1 the default (blob) relaxation spectrum lets each mode cross over from Zimm to Rouse as the chain stretches and the solution crowds. This multimode spectrum has not yet been through peer review. The pure Rouse and Zimm scalings are offered as checks.
    • 

  • A prestretch ε0 is applied affinely to every mode. With more than one mode the fast modes then start far from equilibrium, which is not physical, so we use prestretch with the single-mode model only.
    • 

  • Every key the page writes is read by the C2D2.jl v1.0.0 input readers (StyextRunContext.jl, UsyextRunContext.jl). The inputs are plain TOML and can be edited by hand.
