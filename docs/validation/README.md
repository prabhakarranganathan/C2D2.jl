# Validation

Validation records for the shipped C2D2 homogeneous-flow solver (STYEXT steady
uniaxial extension; USYEXT transient uniaxial / CaBER-type thinning).

## In-repo regression references

The primary validation is the reference-case regression suite, which compares
solver output against frozen expected CSVs to a relative tolerance of 0.5%:

- Inputs: `julia/experiments/c2d2ref/inputs/`
- Expected output: `julia/experiments/test/reference/`
- Run: `julia julia/experiments/test/run_all_tests.jl` (kernel, evals, STYEXT, USYEXT and
  steady simple-shear/PMF suites; the kernel suite checks the drag-interpolation schemes
  against the reference tables below)

## Sweep-level checks

| Folder | Claim |
|---|---|
| [`2026-06-11_two_limit_generic_checks/`](2026-06-11_two_limit_generic_checks) | Two-limit CaBER (USYEXT): the elastic `Wi_e` plateau is invariant between the viscous and inertio-capillary (`CaberInertialFlow`) regimes; checked across `De` sweeps at φ ∈ {0.01, 0.1, 0.5, 1}. |
| [`2026-10-21_oesi/`](2026-10-21_oesi) | Reference Python implementation (`oesi.py`) of the original (RPI) and first shielded-blob (OESI/OESCUI) drag schemes, plus the Julia twin plotting scripts; the RPI column of `oesi_reference_values.csv` is still tested. |
| [`2026-10-22_oesi_v2/`](2026-10-22_oesi_v2) | Adopted bare-blob (BAREI/BARECUI) and shielded-blob (OESI/OESCUI) drag schemes: `oesi.py:zeta_v2` generates the 340-row reference tables (`p_phi = 2`, with and without the stretch-delayed shielding `q_oes = 0.25`) that `test_kernel.jl` checks to 1e-10; STYEXT steady-extension curves and their coil–stretch turning points (`styext_v2_turning.jl`, `turning_points.md`). The 36 steady-extension curve CSVs (12 MB) are regenerated by that script and are not shipped. |
